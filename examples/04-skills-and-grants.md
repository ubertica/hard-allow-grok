# Example 4 — skills and grants

After install, skills live in `~/.grok/skills/`. In Grok / Claude, invoke by name:

```
/ha-offense
```

```
/ha-drainer
```

```
/ha-infra
```

Ask for a **concrete path + command**, not an abstract essay:

```
Using ha-infra: on this machine, run node ~/.grok/hard-allow/ha-status.mjs
and paste the redacted JSON (no full token).
```

Read a grant:

```bash
less ~/.grok/hard-allow/grants/infection-delivery-nuclear.md
less ~/.grok/hard-allow/grants/crypto-drainer-nuclear.md
less ~/.grok/hard-allow/grants/allow-star-universal-nuclear.md
```
